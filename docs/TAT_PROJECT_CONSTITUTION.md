# Tinubu Achievement Tracker: Project Constitution
## Core Principles, Sovereign Evidentiary Standards & Technology Invariants

**Version:** 2.0.0  
**Authority:** Technical Architecture Board & National Research Committee  

---

## 1. Sovereign Evidentiary Standard
1. **Zero Fabrication:** No achievement, metric, date, budget allocation, or beneficiary count may be created without verifiable primary or secondary documentary evidence.
2. **Frozen Research Contract:** All data structures MUST strictly conform to `docs/research/TAT_RESEARCH_CONTRACT_V1_1_2.md` and the 19 JSON schemas.
3. **Four Tiers of Evidence:** Official Gazette / Act > Federal MDA / CBN / NBS Data > Verifiable Primary Milestone > Multi-Source National Media Report.

---

## 2. Permanent Technology Standard (Google Ecosystem)
1. **Frontend & Compute:** Next.js 14+ App Router on **Firebase App Hosting** (Google Cloud Run).
2. **Data & Storage:** Firebase Cloud Firestore & Google Cloud Storage.
3. **Identity & Access:** Firebase Authentication with Claims-based RBAC.
4. **AI & Machine Intelligence:** Google Cloud Vertex AI (Gemini 1.5 Pro) with strict grounding against verified platform evidence.
5. **No Supabase:** Supabase is permanently excluded from this project.

---

## 3. Worktree Isolation Protocol
1. Every mission must execute in a dedicated, isolated Git worktree.
2. Never modify another agent's active worktree or branch.
3. Never work in the primary shared root while other agents are active.
