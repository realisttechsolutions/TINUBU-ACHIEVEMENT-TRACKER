# Quality Control Gates — Tinubu Achievement Tracker V2

This document defines the 5 Quality Control Checkpoints required before record publication.

---

## 1. The 5 Quality Gates
- **Gate 1: Format & Linter Check**: Automated CSV/JSON schema validation.
- **Gate 2: Evidence Attribution Check**: Level 1-5 source verification.
- **Gate 3: Stage & Financial Audit**: Stage boundary enforcement (announcement vs expenditure).
- **Gate 4: Editorial Truth Rules Audit**: 13 Truth Rules audit check.
- **Gate 5: Senior Editor Approval**: Final publication sign-off.
