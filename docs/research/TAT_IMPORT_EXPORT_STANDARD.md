# Import & Export Standards — Tinubu Achievement Tracker V2

This document defines approved research ingestion and data export formats.

---

## 1. Supported Formats
- **CSV**: Primary format for batch CSV research imports (UTF-8, pipe-delimited arrays `|`).
- **JSON / JSON Lines**: Primary format for draft review and structured API payloads.
- **Markdown**: Formats research documentation and editorial reports.
