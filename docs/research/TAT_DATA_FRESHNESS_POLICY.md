# Data Freshness Policy — Tinubu Achievement Tracker V2

This document defines velocity classes and audit thresholds.

---

## 1. Velocity Classes & Thresholds

| Velocity Class | Target Domains | Stale Threshold | Review Frequency |
| :--- | :--- | :--- | :--- |
| **High Velocity** | FX Rates, Inflation, Reserves | 30 Days | Monthly |
| **Medium Velocity** | Quarterly GDP, Beneficiary Disbursement | 90 Days | Quarterly |
| **Low Velocity** | Infrastructure Construction, Legislation | 180 Days | Bi-Annually |
| **Event-Driven** | Policy Announcements, Commissionings | Immediate | Event Trigger |
