# Verification Standards by Record Type — Tinubu Achievement Tracker V2

This document details the minimum verification requirements by record category.

---

## 1. Category Verification Rules

### 1.1 Policy & Legal Reform Records
- Requires Level 1 Official Gazette, Signed Executive Order, or Enacted Act reference.
- Must verify announcement date, approval date, and effective date separately.

### 1.2 Physical Infrastructure Project Records
- Requires proof of physical implementation status (site inspection, Works Ministry report).
- Financial values must explicitly distinguish FEC contract award from disbursed expenditure.

### 1.3 Beneficiary & Programme Records
- Must explicitly separate registered applicants from verified disbursement recipients.
- Requires Level 2 statutory programme report or Level 3 independent evaluation.
